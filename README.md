# Archived development reports

This branch archives the project's development reports and reviews. The plugin source, build files,
test scripts and data live on the `main` branch; nothing here is needed to build or use the plugin.

Layout of `reports/`:

* `reports/README.md` - index of the archived reports and which scripts on `main` regenerate them.
* `reports/REPORT-*.md` - per-workstream reports, plus `DIAGNOSIS.md` and the spec-test, corpus and
  robustness result tables.
* `reports/research/` - analyses of external WebAssembly tools considered for reuse.
* `reports/full-code-review-2026-10-15/` - the full code review and its supporting review receipts.
